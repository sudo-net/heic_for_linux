# HEIC for Linux (`heic_for_linux`)

Bringt dynamische Apple `.heic`-Hintergrundbilder mit echter astronomischer Sonnenstandsberechnung (offline per Postleitzahl) samt automatischem Light/Dark-Mode-Wechsel auf den Linux-Desktop.

* **Aktueller Stand (v0.1.0 Beta):** Optimiert für GNOME (GTK4 / Libadwaita). Unterstützung für weitere Desktops wie KDE Plasma ist in Planung.
